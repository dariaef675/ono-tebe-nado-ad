# Оно тебе надо

Лендинг аукциона вещей, в которые никто не верил: фильм режиссёра, бросившего киношколу, «Улисс» Джойса, работа Кандинского. Учебный проект Яндекс Практикума.

**Сайт:** https://dariaef675.github.io/ono-tebe-nado-ad/

## Что на странице

- Шапка с навигацией, логотипом и контактами
- Обложка с заголовком и кнопкой «Сделать ставку»
- Секция «Лоты» с тремя карточками
- Секция «Об аукционе»
- Подвал с контактами, меню и ссылками на соцсети

## Технологии

- HTML5, семантическая разметка
- CSS3: Grid Layout и Flexbox
- Именование классов по БЭМ
- Локально подключённый шрифт Raleway (woff2, woff)

## Структура проекта

```
├── index.html
├── fonts/      # шрифт Raleway и fonts.css
├── images/     # обложка, фото лотов, логотипы, иконки
└── styles/
    ├── global.css   # базовые стили
    └── style.css    # стили блоков
```

## Запуск локально

```bash
git clone git@github.com:dariaef675/ono-tebe-nado-ad.git
cd ono-tebe-nado-ad
```

Откройте `index.html` в браузере — сборка не нужна.
